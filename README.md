# webDMX followspot AI
<img align="right" width="100" src="https://avatars.githubusercontent.com/u/184787984">
Tool for using moving lights as intelligent followspots with camera-based, AI-powered person tracking.<br/>
Link the pan and tilt function of the moving light to <i>webDMX followspot AI</i> via Art-Net.<br/>
After calibrating reference points in the camera image, the target position of the light can be controlled manually or automatically through real-time video analysis and AI-powered person tracking.

## Dependencies
![.Net](https://img.shields.io/badge/.NET-5C2D91?style=for-the-badge&logo=.net&logoColor=white)
